# RBAC Group Mapping Resource

Management of RBAC Group Mappings in Instana. A group mapping connects an IdP (LDAP, OIDC, SAML) attribute key/value pair to an Instana group, so that users whose IdP token contains that pair are automatically assigned to the corresponding group upon login.

API Documentation: [Group Mapping Rest API](https://developer.ibm.com/apis/catalog/instana--instana-rest-api/api/API--instana--instana-rest-api-documentation#createGroupMapping)

## Example Usage

### Basic Group Mapping

```hcl
resource "instana_rbac_group_mapping" "example" {
  key      = "department"
  value    = "engineering"
  group_id = "60845e4e5e6b9cf8fc2868da"
}
```

### Group Mapping Scoped to a Team

```hcl
resource "instana_rbac_group_mapping" "team_scoped" {
  key      = "department"
  value    = "platform"
  group_id = "60845e4e5e6b9cf8fc2868da"
  team_id  = "5e6b9cf8fc2868da60845e4e"
}
```

### Multiple Group Mappings with `for_each`

```hcl
locals {
  group_mappings = {
    engineering = {
      key      = "department"
      value    = "engineering"
      group_id = "60845e4e5e6b9cf8fc2868da"
    }
    operations = {
      key      = "department"
      value    = "operations"
      group_id = "9cf8fc2868da60845e4e5e6b"
    }
  }
}

resource "instana_rbac_group_mapping" "mappings" {
  for_each = local.group_mappings

  key      = each.value.key
  value    = each.value.value
  group_id = each.value.group_id
}
```

### Referencing an Existing Role and Team

```hcl
# Lookup the Role (used as group_id)
data "instana_rbac_role" "engineering_role" {
  name = "Engineering Access"
}

# Lookup the Team (used as team_id)
data "instana_rbac_team" "platform_team" {
  tag = "platform"
}

resource "instana_rbac_group_mapping" "saml_department_mapping" {
  key      = "department"
  value    = "engineering"
  group_id = data.instana_rbac_role.engineering_role.id
  team_id  = data.instana_rbac_team.platform_team.id
}
```

## Generating Configuration from Existing Resources

If you have already created a group mapping in Instana and want to generate the Terraform configuration for it, you can use Terraform's import block feature with the `-generate-config-out` flag.

This approach is also helpful when you're unsure about the correct Terraform structure for a specific resource configuration. Simply create the resource in Instana first, then use this functionality to automatically generate the corresponding Terraform configuration.

### Steps to Generate Configuration

1. **Get the Resource ID**: Locate the ID of your group mapping in Instana — via the Instana UI or API.

2. **Create an Import Block**: Create a new `.tf` file (e.g., `import.tf`) with an import block:

```hcl
import {
  to = instana_rbac_group_mapping.example
  id = "resource_id"
}
```

Replace:
- `example` with your desired Terraform block name
- `resource_id` with your actual group mapping ID from Instana

3. **Generate the Configuration**: Run the following Terraform command:

```bash
terraform plan -generate-config-out=generated.tf
```

This will:
- Import the existing resource state
- Generate the complete Terraform configuration in `generated.tf`
- Show you what will be imported

4. **Review and Apply**: Review the generated configuration in `generated.tf` and make any necessary adjustments.

   - **To import the existing resource**: Keep the import block and run `terraform apply`. This will import the resource into your Terraform state and link it to the existing Instana resource.

   - **To create a new resource**: Remove the import block, adjust the configuration as needed, and run `terraform apply` to create a new resource in Instana.

```bash
terraform apply
```

## Argument Reference

* `key` - **Required** - The IdP attribute key used for the group mapping (e.g. `department`, `role`).
* `value` - **Required** - The IdP attribute value that must match for this mapping to apply (e.g. `engineering`).
* `group_id` - **Required** - The ID of the Instana group that matched users will be assigned to.
* `team_id` - **Optional** - The ID of the Instana team to additionally scope this mapping to.

## Attributes Reference

* `id` - The auto-generated ID of the group mapping.

## Import

RBAC Group Mappings can be imported using the `id` of the mapping, e.g.:

```bash
$ terraform import instana_rbac_group_mapping.my_mapping 60845e4e5e6b9cf8fc2868da
```

## Notes

* The `id` is auto-generated by Instana and cannot be set manually.
* The `key`/`value` pair must match an attribute present in the user's IdP token for the mapping to take effect at login.
* When `team_id` is specified, the mapping is additionally scoped to the given team — only users belonging to that team will have the mapping applied.
* Group mappings are evaluated at login time; changes take effect on the user's next authentication.
* Use `for_each` to efficiently manage multiple mappings with similar structures.
